CẤU TRÚC THƯ MỤC
- index.html: trang portfolio hoàn chỉnh
- styles.css: CSS, hiệu ứng và responsive
- dap-an.txt: đáp án 21 câu và giải thích breakpoint
- screenshots/desktop.png: ảnh trang ở 1440px
- screenshots/tablet.png: ảnh trang ở 768px
- screenshots/mobile.png: ảnh trang ở 480px
- screenshots/wireframe.png: phác thảo bố cục responsive

CÁCH MỞ TRANG
1. Giải nén thư mục.
2. Mở index.html bằng Chrome/Edge hoặc mở thư mục bằng VS Code rồi dùng Live Server.
3. Mở DevTools (F12), bật Device Toolbar để kiểm tra 1440px, 768px và 480px.

BREAKPOINTS
- Tablet: max-width: 768px.
- Mobile: max-width: 480px.

GHI CHÚ KIỂM THỬ
Các ảnh trong thư mục screenshots là ảnh render của chính index.html ở các viewport đã ghi. Nên mở kiểm tra lần cuối trên máy tính của bạn trước khi nộp LMS.
